# Data dictionary

## Real data: UCI SECOM (`raw/`)
- **`secom.data`**: 1,567 rows (one per production run) × 590 space-separated sensor/process measurements. The columns are unnamed (`feature_000`…`feature_589`). About 4.5% of values are missing (`NaN`), and some columns are constant. Cleaning these is part of the silver layer.
- **`secom_labels.data`**: 1,567 rows in two columns: `label` (−1 = pass, 1 = fail) and `timestamp` (`"DD/MM/YYYY HH:MM:SS"`, July–October 2008). Row *i* matches row *i* of `secom.data`.
- Class balance: 1,463 pass, 104 fail (6.6%).
- Source: UCI Machine Learning Repository, CC BY 4.0. https://archive.ics.uci.edu/dataset/179/secom

## Synthetic data (`synthetic/`), generated by `scripts/generate_synthetic.py` (seed 42)
SECOM has no tool, product or customer fields, so these tables add realistic context. **They are simulated, not real Lumentum or fab data.** Say so wherever results from them are shown.

### `production_context.csv` (one row per run, joins to SECOM by row order / `run_id`)
| Column | Description |
|---|---|
| `run_id` | `RUN-00001`… (row 1 of SECOM = RUN-00001) |
| `timestamp` | Test timestamp from SECOM labels |
| `lot_id` | Lot of 25 consecutive runs |
| `tool_id` | ETCH-01 to ETCH-04. **ETCH-03 is seeded as the problem tool** (more failures) |
| `chamber` | A / B |
| `product_family` | DFB laser, EML laser, VCSEL array, Coherent transceiver |
| `shift` | Day (6–13h), Swing (14–21h), Night |
| `units_in_run` | Units produced in the run (400–600) |

### `customer_returns.csv` (one row per returned unit; only passed runs ship)
| Column | Description |
|---|---|
| `return_id` | `RMA-00001`… |
| `run_id` | Production run the unit came from |
| `ship_date`, `return_date` | Ship 3–14 days after test; returned 20–180 days after ship |
| `customer_region` | North America, EMEA, APAC, China |
| `failure_mode` | Low optical power, Wavelength drift, Hermeticity leak, Connector damage, No fault found |

Seeded patterns to find: higher fail and return rates on ETCH-03, and more returns from runs made within 3 runs of a failed run (marginal process).
